# 🧩 Анти-ИИ: Мозаика / Human Vision Puzzle

Бесплатный социальный игровой проект, созданный как манифест человеческого разума против машинных алгоритмов. В эпоху, когда нейросети идеально имитируют искусство, эта игра доказывает: искусственный интеллект видит лишь холодные пиксели, но только человек способен увидеть целостный смысл и собрать образ из хаоса осколков.

Игра разработана на чистом HTML5/CSS3/JavaScript без использования тяжелых внешних графических или игровых движков. Проект полностью автономен, оптимизирован под мобильный формат 9:16 и запускается на любом устройстве без подключения к интернету.

---

## 🌪️ Ключевые особенности игры

* **Механика честной рокировки:** Фрагменты мозаики перемещаются по принципу "пятнашек" — когда вы переносите фрагмент на новую клетку, он меняется местами с тем кусочком, который стоял там ранее. Это исключает наслоение деталей и делает сборку глубоко логической.
* **Свободный выбор (Drag-and-Drop):** Игрок может кликнуть или тапнуть на абсолютно любой незаблокированный фрагмент на поле, чтобы начать управлять им.
* **Два уровня сложности:** 
  * *Уровень 1:* Классическая сетка 3х4 (12 фрагментов) для разминки.
  * *Уровень 2:* Усложненная сетка 4х5 (20 фрагментов) с новым изображением, заставляющая алгоритмы ИИ трещать по швам.
* **Наказание за ошибку:** При нажатии кнопки фиксации правильные детали закрепляются в матрице и становятся полупрозрачными, а ошибочные — со звуком сбоя отлетают в случайную позицию, совершая рокировку со случайным соседом.

---

## 🛠️ Технологический стек

* **Язык и ядро:** Чистый JavaScript (Vanilla JS, ES6+) без сторонних зависимостей.
* **Графика:** Нативный HTML5 Canvas (динамическая нарезка, масштабирование под реальный размер файлов изображений и отрисовка сетки в реальном времени).
* **Звук:** Web Audio API (звуковые эффекты клика, фиксации ✨ и сброса хаоса генерируются кодом на лету с помощью встроенных осцилляторов, никаких внешних `.mp3` файлов).
* **Анимация:** Попиксельное покадровое покачивание активного фрагмента ветром на основе `requestAnimationFrame`.
* **Стилизация:** Адаптивный CSS под мобильный формат 9:16 с постоянным неоновым логотипом `favicon.ico` вверху по центру экрана.

## 📁 Структура файлов проекта

Для корректной работы игры на Vercel или локально в корне репозитория должны лежать следующие файлы:
* 📄 `index.html` — основной код игры.
* 🖼️ `favicon.ico` — иконка проекта для вкладки и шапки сайта.
* 🖼️ `ai_image.jpg` — вертикальное изображение для 1 уровня (3х4).
* 🖼️ `ai_image2.jpg` — вертикальное изображение для 2 уровня (4х5).
* 📄 `robots.txt` — файл инструкций для поисковых роботов.
* 📄 `sitemap.xml` — карта сайта для ускорения индексации в Google/Яндекс.

## 📱 Управление

* **Мышь / Сенсор:** Зажмите фрагмент и тяните влево или вправо для перемещения по столбцам.
* **Экранные кнопки / Клавиатура:** 
  * ◀ и ▶ — движение по горизонтали.
  * ▲ и ▼ (или вертикальный свайп по фрагменту) — рокировка местами с верхним или нижним соседом.
  * ✨ (или `Space` / `Enter` на ПК) — фиксация фрагмента на его законном месте.
